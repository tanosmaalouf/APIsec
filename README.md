# Secure Auth API with Node.js, Express, MongoDB, and JWT

This project is a secure RESTful API built using **Node.js**, **Express**, and **MongoDB**, featuring **user registration**, **login**, **JWT-based authentication**, and **role-based access control**.

## 🔐 Features

- User registration with password hashing (bcrypt)
- Login and JWT token generation
- Protected routes with middleware authentication
- Role-based authorization (e.g., admin-only routes)
- Security best practices (Helmet, CORS, Rate Limiting)
- Frontend integration-ready (CORS-enabled for React)
- MongoDB Atlas connection setup
